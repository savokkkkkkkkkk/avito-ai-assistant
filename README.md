# AI Ассистент для улучшения объявлений на Авито

Веб-приложение для управления объявлениями с интегрированным AI-ассистентом. Позволяет просматривать, редактировать объявления, а также улучшать их описание и определять рыночную цену с помощью AI.

## 🚀 Технологии

- **Frontend:** React 18, TypeScript, Vite
- **UI библиотека:** Ant Design
- **Маршрутизация:** React Router v6
- **Управление состоянием:** React Query (серверные данные)
- **HTTP клиент:** Fetch API
- **AI интеграция:** Ollama (локальная LLM)

## 📋 Требования

- Node.js 20+
- npm или yarn
- 8+ ГБ оперативной памяти (для работы LLM)

## 🔧 Установка и запуск

### 1. Клонирование репозитория
git clone (https://github.com/savokkkkkkkkkk/avito-ai-assistant)
cd avito-ai-assistant

### 2. Настройка и запуск backend сервера
bash
cd server
npm install
npm start
Сервер запустится на http://localhost:8080

### 3. Настройка и запуск frontend приложения
bash
cd client
npm install
npm run dev
Приложение запустится на http://localhost:2511 и автоматически откроет страницу со списком объявлений.

### 4. Настройка AI (Ollama)
Установка Ollama
Windows:

Скачайте установщик с официального сайта

Запустите установку

macOS:

bash
curl -fsSL https://ollama.com/install.sh | sh
Linux:

bash
curl -fsSL https://ollama.com/install.sh | sh
Загрузка модели
bash
# Загружаем лёгкую модель (рекомендуется для 8 ГБ ОЗУ)
ollama pull qwen2.5:3b

# Альтернативные модели:
# ollama pull phi3:mini   (2.2 ГБ)
# ollama pull tinyllama   (0.6 ГБ)
Запуск Ollama
bash
ollama serve
Примечание: Ollama должен быть запущен в отдельном терминале перед использованием AI-функций.

### 5. Проверка работы
Откройте http://localhost:2511/ads

Должен отобразиться список объявлений

Нажмите на любое объявление → просмотр деталей

Нажмите "Редактировать" → форма редактирования

Нажмите "Придумать описание" → AI сгенерирует текст

### 6. Черновики
Изменения формы редактирования автоматически сохраняются в localStorage и восстанавливаются при обновлении страницы с подтверждением пользователя.

tsx
const saveDraft = (values) => {
  const draftKey = `draft_${id}`
  const draftData = { ...values, savedAt: new Date().toISOString() }
  localStorage.setItem(draftKey, JSON.stringify(draftData))
}

// При загрузке страницы
Modal.confirm({
  title: 'Найден черновик',
  content: `Хотите восстановить несохранённые изменения?`,
  onOk: () => loadDraft(),
  onCancel: () => clearDraft(),
})
